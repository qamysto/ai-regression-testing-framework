# Roles

The platform uses four final roles:

| Role | Purpose |
| --- | --- |
| Admin | Manage users, projects, settings, release gates, and all QA workflows. |
| QA | Manage requirements, generate and review AI test cases, run suites, review reports. |
| Developer | View runs and failures, add comments, help resolve assigned failures. |
| Viewer | Read-only access to dashboards, coverage, runs, and release reports. |

AI-generated output is always a draft or suggestion. QA or Admin approval is required before generated test cases count as approved regression coverage.
